# AGENTS.md

Orientation for AI agents working in this repo.

## What this is

Scaffold for a Corticon hackathon project. It is intentionally empty —
no code, no build, no server yet. As we add structure, update this file
to be the 30-second entry point for any agent starting work here.

## Skills available

The Matt Pocock skills plugin is enabled for this repo. Use them:

- `/code-review` — review changes since a fixed point
- `/tdd` — test-first feature work and bug fixes
- `/diagnosing-bugs` — systematic diagnosis for hard bugs
- `/domain-modeling` — pin down terminology, write CONTEXT.md / ADRs
- `/codebase-design` — design or deepen module interfaces
- `/research` — investigate a question against high-trust sources
- `/writing-for-agents` — keep docs (including this file) agent-readable
- `/grilling` — stress-test a plan or decision before committing to it

## Conventions

- Keep docs agent-readable; this file is the entry point.
- Commit secrets-free — `.env` is gitignored.
- Update this file when the project's shape changes.
