Market & value

Who pays, how we price it, where we start — and why that order.

Value proposition

FraudLens turns the clinical note into an audit trail — catching upcoded, unbundled, and unsupported claims before a provider submits, or before a payer pays out. One reader, two customers, one shared question: does the code match the note?

How we measure value

Priced against the dollars it protects, not seats. Payers pay a share of the overpayment it prevents — the shared-savings model the payment-integrity industry already trusts. Providers pay per encounter checked, priced against the clawback risk it removes.

Payers — % of prevented overpayment Providers — per-encounter check fee
Geography & language

Launching in the Nordics and wider EU, where Corti's clinical-note infrastructure and hospital relationships already run in-language. From there, into the US — the market with the largest fraud exposure and the CPT / HCC coding structure FraudLens is built to read.

EU / Nordic — beachhead United States — scale market
Why this path

Coding standards make the mismatch machine-legible everywhere claims are billed — CPT, ICD-10, HCC, NCCI. Corti already sits inside the documentation layer these customers use daily, and getting paid only when we catch something real shortens the sales cycle in a market that's historically wary of black-box scoring.

We only get paid when the flag is real — the same discipline built into how FraudLens reads the note.

Paid to catch it. Not to promise it.
